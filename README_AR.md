# Midasbuy Egypt v2.0 — مشروع KlencodIDE

## التوافق
- Kotlin / Android
- compileSdk 34 و targetSdk 34 و minSdk 23
- Java 17
- مناسب مبدئيًا لـ Samsung Galaxy A23 / Android 14

## المزايا
- WebView لفتح متجر Midasbuy Egypt.
- شاشة افتتاحية قصيرة متحركة.
- واجهة علوية بها الرئيسية والتحديث والرجوع.
- شريط تقدم تحميل.
- كشف انقطاع الاتصال وإظهار زر إعادة المحاولة.
- دعم JavaScript و DOM Storage وملفات الاختيار والتنزيلات.
- الاحتفاظ بحالة التصفح عند إعادة إنشاء النشاط.

## البناء
1. فك ضغط ZIP.
2. افتح مجلد المشروع في KlencodIDE.
3. تأكد من توفر Android SDK 34 و JDK 17.
4. نفّذ Gradle Sync ثم Build APK.
5. اختبر تسجيل الدخول وصفحات الشحن والدفع على جهازك.

## تنبيهات مهمة
- هذه نسخة WebView وليست تطبيقًا رسميًا من Midasbuy.
- الأيقونة وحرف M تصميم مؤقت وليسا الشعار الرسمي.
- لا يتم تجاوز أي حماية أو صفحة تحقق أو نظام دفع تابع للموقع.
- لم يتم إرفاق APK مبني أو الادعاء بأن البناء تم اختباره هنا.
- بعض مزايا الموقع قد تعتمد على سياسات WebView أو تحديثات Midasbuy؛ اختبر تسجيل الدخول والدفع فعليًا قبل الاعتماد عليها.
